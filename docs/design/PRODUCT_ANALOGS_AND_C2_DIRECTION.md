# OquMap — Civic Humanist C2

Статус: выбранное направление для дальнейшей реализации.

## Что сохраняем из варианта C

- Тёплый светлый фон вместо холодной панели администратора.
- Синие числа как главный визуальный язык доказательств.
- Последовательность «сигнал → ошибка → цель → материал → действие».
- Редакционная типографика, тонкие разделители и большое количество воздуха.
- Человеческий язык выводов и явное отделение фактов от гипотез.

## Что улучшает версия C2

1. Отчёт превращается в рабочее пространство исследования: каждый шаг цепочки выбирается и раскрывает доказательства.
2. У каждого вывода видны источник, выборка, уверенность и ограничение.
3. Причинность не имитируется: неподтверждённые связи отмечаются охрой и формулируются как гипотезы для пилота.
4. Любой вывод заканчивается следующим действием, ответственностью и датой повторной проверки.
5. Одинаковая визуальная система работает и для расследования, и для сравнения учебников.

## Правила реализации

- Основной шрифт: Onest Variable; резервный для казахского и редких символов — Noto Sans.
- Базовый текст не меньше 15–16 px; числа и выводы образуют отдельный визуальный слой.
- Навигация остаётся узкой и спокойной; не превращать интерфейс в сетку одинаковых карточек.
- Синий означает данные, выбранное состояние и действия. Охра — неопределённость или ограничение. Красный — только критическая ошибка данных.
- Все элементы, похожие на ссылки или кнопки, должны быть интерактивны в демо.
- Каждый вывод обязан иметь `source`, `sample`, `confidence`, `limitation`, `updatedAt`.
- Нельзя показывать «AI confidence» без объяснимого основания и ссылки на исходные данные.
- Для презентации нужен отдельный режим без навигационного шума, но с источниками и ограничениями.

## Сценарий демо для жюри

1. Методист видит падение результата по дробям — 62%.
2. Переходит по цепочке к ошибке M2 и цели 6.2.1.
3. Выбирает страницу 47 и открывает доказательство.
4. Сравнивает два учебника по конкретным подцелям.
5. Видит разрыв по вычитанию и создаёт пилот с шестью заданиями.
6. Система назначает повторную проверку через три недели и сохраняет протокол решения.

Оба изображения созданы встроенным генератором изображений в режиме редактирования/вариации с сохранением исходного Civic Humanist как визуального референса.

- Prompt 1: сохранить светлую Civic Humanist-систему, превратить причинную цепочку в интерактивное расследование, добавить инспектор источника, происхождение данных, ограничения и decision dock.
- Prompt 2: продолжить ту же систему на экране сравнения учебников, привязать сравнение к цели программы и завершить конкретной рекомендацией для пилота.
