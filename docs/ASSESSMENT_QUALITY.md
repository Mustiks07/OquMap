# Assessment Quality Lab (method `aq-v1`)

Код: `apps/api/oqumap/analytics/assessment_quality.py` (чистые функции), `apps/api/oqumap/services/quality.py`
(загрузка, снимок `AnalysisRun` вида `assessment_quality`), тесты `apps/api/tests/test_assessment_quality.py`.
Экраны: `/quality`, `/quality/:assessmentId`.

## 1. Единица анализа
Все показатели считаются **внутри одной проверки (`Assessment`) одной формы**. Разные формы и шкалы не
объединяются: у задания, входящего в несколько проверок, `GET /quality/items/{id}` возвращает статистику по
каждой проверке отдельно, `pooled = null`, `pooled_unavailable_reason = administrations_not_pooled`.
Ответ содержит только агрегаты — идентификаторы учеников не возвращаются.

## 2. Состояния измерения и знаменатели
| Состояние | Источник | Учёт |
|---|---|---|
| Назначен | ученики классов, у которых есть хотя бы одна запись присутствия на эту проверку | `assigned` |
| Присутствовал | `sittings.status = present` | `present` — знаменатель всех показателей заданий |
| Отсутствовал | `sittings.status = absent` | `absent`; балла нет (не 0), в знаменатели заданий не входит |
| Без записи | назначен, но нет записи присутствия | `no_sitting_record` |
| Ответил | `responses.status = answered` | измеренный балл (0 — верный ноль) |
| Пропустил | `status = omitted` | `as_incorrect` (по умолчанию): 0 баллов; `exclude`: вне числителя и знаменателя |
| Нет строки | присутствовал, но строки по заданию нет | `missing` — отдельно от пропуска и от неверного ответа |

`assigned = present + absent + no_sitting_record`. `expected_item_responses = present × n_items`;
`completion_rate = answered / expected`, `omission_rate = omitted / expected`, `missing_rate = missing / expected`.

**Попытки**: `attempt_rule = first` (по умолчанию) или `last` — на пару (ученик, задание) остаётся одна строка;
число отброшенных строк и учеников с повторами возвращается в `exclusions`. Повторы никогда не создают новых
учеников.

## 3. Показатели формы
* **Итоговый балл ученика** = Σ баллов / Σ максимумов по заданиям с пригодным значением (корректно для частичного
  кредита: задание на 2 балла с 1 баллом даёт 0,5, итог — не среднее долей).
* Распределение: n, среднее, медиана, SD (ddof = 1), min/max, доля на нижней (0) и верхней (1) границе,
  гистограмма из 10 интервалов.
* **α Кронбаха** = k/(k−1)·(1 − Σσ²ᵢ/σ²ₓ) на полных наборах (матрица долей; пропуски по правилу; отсутствующая
  строка делает набор неполным), выборочные дисперсии. Не рассчитывается (`value = null` + причина) при
  `too_few_items` (k < 3), `too_few_learners` (n < 30 полных наборов), `zero_total_variance`.
* **Разрезы** по языку обучения и классу обучения (grade) — только по присутствовавшим; группы < 20 учеников
  скрываются, а если скрыта ровно одна группа, скрывается и следующая по размеру (дополнительное скрытие, чтобы
  значение нельзя было вычесть из общего). Разрезы по классам-коллективам, учителям и школам не строятся.

## 4. Показатели задания
| Показатель | Определение |
|---|---|
| `p_value` | средняя доля балла среди присутствовавших (пропуск — по правилу; нет строки — вне знаменателя) |
| `p_value_among_answered` | то же только среди ответивших |
| `omission_rate` | omitted / (answered + omitted) |
| `item_rest_correlation` | Пирсон между долей балла по заданию и **скорректированным итогом** (итог без этого задания); n ≥ 30, иначе `too_few_learners`; при нулевой дисперсии — `zero_variance` |
| `upper_lower` (D) | доля балла в верхней группе − в нижней; группы по 27% (floor) учеников, упорядоченных по скорректированному итогу, равенства разбиваются по id ученика (детерминированно); n ≥ 30 |
| Дистракторы | для каждого варианта: число и доля выбравших среди ответивших, средний скорректированный итог выбравших, точечно-бисериальная корреляция выбора со скорректированным итогом (при ≥ 20 ответивших); недопустимые значения ответа считаются отдельно |
| Связи | цели (`item_objectives`, со статусом), коды типичных ошибок дистракторов |

## 5. Сигналы для проверки (не вердикт)
| Код | Правило |
|---|---|
| `too_easy` (info) | p > 0,90 |
| `too_hard` (warn) | p < 0,20 |
| `negative_discrimination` (warn) | r(задание—остальное) < 0 или D < 0 |
| `low_discrimination` (info) | min(r, D) < 0,20 |
| `high_omission` (warn) | доля пропусков > 10% |
| `non_functional_distractors` (info) | неверный вариант выбирают < 5% ответивших |
| `suspicious_distractor` (warn) | r выбора дистрактора > 0,05, либо его выбирают ученики с бо́льшим средним итогом, чем выбравшие ключ, **и** r выбора > 0 |
| `key_chosen_less_than_distractor` (warn) | ключ выбирают реже, чем какой-либо дистрактор |
| `mapping_unconfirmed` (info) | у задания нет подтверждённой связи с целью |

Пороговые значения возвращаются в `thresholds`; каждый флаг содержит `params` и текст RU/KZ.

## 6. Происхождение и ограничения
Ответ: `method_version`, `dataset_version`, `current_dataset_version`, `is_stale`, `generated_at`,
`provenance.analysis_id`, `rules`, `exclusions`, `limitations`. Одинаковые входы → тот же снимок.
Ограничения: метод классической теории тестов, не IRT; пороги — условные скрининговые значения; на малых выборках
показатели неустойчивы (поэтому минимумы n); синтетические данные демо иллюстрируют метод.

## 7. Демо
Набор `measurement_loop`, форма `F-T3-DIAG` (проверки `DIAG-BASE`, `DIAG-END`): задания Q03 (два защитимых
ответа → `suspicious_distractor`), Q05 (ошибочный ключ → `negative_discrimination`), Q07 (вариант, который никто не
выбирает), Q09 (очень лёгкое), Q11 (много пропусков), Q12 (очень трудное); остальные задания без предупреждений.

## 8. Раунд 2: явное назначение, видимость заданий, DIF screening

### 8.1 Явное назначение проверки классам (`assessment_cohorts`)
* `GET/PUT /quality/assessments/{id}/assignments` (изменение — методист, с аудитом). Источник строки: `seed`, `manual`
  (`import` зарезервирован: импорт в этой ветке не меняется).
* При наличии явных назначений `assigned` = ученики назначенных классов; класс без единой записи присутствия входит в
  `no_sitting_record`, число таких классов — `exclusions.assigned_cohorts_without_records` и отдельное ограничение.
  Присутствовавшие вне назначения считаются отдельно (`present_outside_assignment`). Инвариант:
  `(present − present_outside) + (absent − absent_outside) + no_sitting_record = assigned`.
* Без явных назначений (старые проверки): `assignment_scope = inferred_from_sittings`, `assigned_is_exact = false`,
  ограничение `assignment_inferred` — выведенное число не выдаётся за точное.
* Набор назначений входит в отпечаток снимка: изменение назначения даёт новый `analysis_id`.

### 8.2 Видимость задания
`GET /quality/items/{id}` возвращает задание (условие, варианты, ключ) только если оно входит хотя бы в одну проверку
организации; `dataset_id` строго ограничивает область. Для общих программ (`org_id = NULL`) одного факта
существования задания недостаточно → 404.

### 8.3 Языковой DIF screening (`dif-mh-v1`, `GET /quality/assessments/{id}/dif?reference=ru&focal=kz`)
* Одна форма; только дихотомические задания (максимум 1 балл, баллы 0/1), полные наборы ответов, пропуск = 0.
* Сопоставление по *rest score* — сумме остальных дихотомических заданий (анализируемое исключено); страты без
  одной из групп не используются.
* Mantel–Haenszel: `α_MH`, `MH D-DIF = −2,35·ln α_MH`, SE по Robins–Breslow–Greenland, 95% интервал, χ² с поправкой
  на непрерывность. Категории screening: A (|D| < 1 или p ≥ 0,05), C (|D| ≥ 1,5 и |D| − 1,96·SE > 1), B — иначе.
* Минимум 100 учеников в каждой языковой группе; размеры групп < 10 скрываются. Причины недоступности:
  `insufficient_sample`, `single_language_group`, `near_constant_item`, `no_informative_strata`,
  `degenerate_odds_ratio`.
* Результат называется `dif_screening_signal`: повод для экспертной проверки перевода/контекста, не доказательство
  предвзятости. IRT не используется; CTT/DIF не заменяют психометрическую экспертизу.
* Демо: классы M05/M06 набора `measurement_loop` — казахский язык обучения; Q10 намеренно труднее для них (+1,5 логита,
  ожидается B/C), Q08 — такая же текстовая задача без сдвига (ожидается A). Тесты: `tests/test_dif.py`.
