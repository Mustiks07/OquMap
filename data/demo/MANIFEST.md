# Демонстрационные данные OquMap

**Все данные синтетические** (`is_synthetic=true`). Ученики, классы, учителя и школы — псевдонимные коды; «Издание
A/Б» — собственные демонстрационные пособия OquMap, не связанные с реальными издательствами. Размер корпуса не
означает статистической мощности или доказанного эффекта.

## Как получаются данные
Генератор `apps/api/oqumap/demo/generator.py` (фиксированные seed) → CSV → **обычный конвейер импорта**
(validate → commit) в `apps/api/oqumap/demo/seed.py`. Сгенерированные CSV основного корпуса и сценариев пишутся в
`data/demo/generated/` (не хранятся в git, воспроизводимы). Файлы для ручной загрузки хранятся в `data/demo/imports/`.

Механизм:
```
θ_ученика = эффект_школы + эффект_класса (N(0, 0.2)) + N(0, 1)
входная:   P(верно) = σ(1.2·(θ − b_задания + 0.3))
итоговая:  P(верно) = σ(1.2·(θ + 0.6 + эффект[издание, тема] − b_задания − сдвиг_темы))   (сдвиг T3 = 0.35)
неверный ответ → дистрактор с весами по коду ошибки (add_across: A 3.0, B 1.5; иначе 1–1.5)
пропуск: P = 0.02 + 0.04·σ(−θ); отсутствие: 3–4% на проверку; повторные попытки T3 в двух классах
```

## Файлы для загрузки
* `imports/followup_2026_2027.csv` — повторная проверка (форма `F-FU`, шкала `S-POST`), загружается в `base`.
* `imports/upload_sample_with_errors.csv` — 24 ученика + 10 намеренно ошибочных строк (неизвестное задание,
  балл выше максимума, нечисло, пустой ученик, неверный статус, дубликат, задание не из формы, ученик в двух классах,
  формулоподобный код, пропуск с баллом).
* `imports/grades_only_sample.csv` — только итоговые оценки (система объясняет, каких полей не хватает).

## Учебные материалы
`materials/demo_posobie_A.pdf` («правило → пример → упражнения», печатные номера страниц 12–17 отличаются от
физических 2–7) и `materials/demo_posobie_B.docx` («модель → обсуждение → правило», без номеров страниц, якоря
абзацев). Содержит намеренный «тестовый фрагмент безопасности» с инструкцией — проверка того, что текст документов
обрабатывается как данные. Математика проверена вручную.

`manifest.json` пересоздаётся seed-скриптом и содержит идентификаторы и параметры наборов.
